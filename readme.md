# Vision Dataset Viewer

Простой инструмент для визуализации и редактирования датасетов компьютерного зрения в форматах **YOLO** и **COCO** с помощью [FiftyOne](https://docs.voxel51.com/).

## Возможности

- Интерактивный просмотр датасета через локальный интерфейс FiftyOne.
- Поддержка форматов разметки YOLO и COCO.
- Загрузка частей датасета: `train`, `val`, `test`.
- Отображение изображений и bounding box-разметки.
- Редактирование bounding-box разметки.

## Зависимости

```bash
pip install fiftyone pyyaml
```

## Использование

1. Указать путь к YAML-файлу датасета (YOLO) или директории датасета (COCO).
2. Запустить соответствующий скрипт:

```bash
python yolo_viewer.py
```

или

```bash
python coco_viewer.py
```

После запуска откроется FiftyOne App, в котором можно просматривать изображения и их разметку.
